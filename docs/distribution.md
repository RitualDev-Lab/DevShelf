# 🚀 DevShelf Growth & Distribution Engine

> Actionable distribution playbook to turn DevShelf's 520+ listed tools into organic discovery channels, build developer trust, and amplify community contributors.

---

## 🎯 1. The Core Distribution Flywheel

DevShelf differentiates from static repositories like `public-apis` and `free-for-dev` through a closed-loop developer flywheel:

```
[Developer submits tool/API]
            ↓
[Automated PR validation & Merge]
            ↓
[Bot drops celebration comment with README badge & tweet link]
            ↓
[Maintainer embeds badge & shares on X / LinkedIn]
            ↓
[DevShelf tags maintainer on weekly spotlight]
            ↓
[New developers discover DevShelf and submit their tools]
```

## 🤖 3. Model Context Protocol (MCP) Registries

DevShelf includes an official MCP server (`npx devshelf-mcp`). Listing DevShelf across emerging MCP registries brings steady AI-first inbound discovery:

### Submission Targets:
1. **[Smithery.ai](https://smithery.ai)** &mdash; `smithery submit devshelf-mcp`
2. **[Glama MCP Directory](https://glama.ai/mcp)** &mdash; Submit GitHub repo `RitualDev-Lab/DevShelf`
3. **[PulseMCP](https://pulsemcp.com)** &mdash; Submit stdio protocol spec
4. **[Awesome MCP Servers](https://github.com/punkpeye/awesome-mcp-servers)** &mdash; Submit PR under "Developer Tools / Utilities"

### Hook for MCP Registries:
> *"Ask your AI coding assistant (Claude, Cursor, Windsurf) to find verified free APIs, vector DBs, and open-source alternatives without leaving your editor."*
