💬 Frequently Asked Questions

Can any developer or maintainer use this badge? ▼

Yes! If your tool is listed on DevShelf or if you maintain an open-source project that respects zero-paywall developer principles, you are free to embed this badge.

Do these SVG badges affect repository loading performance? ▼

Not at all. The SVGs are lightweight (<1.5 KB), pure vector graphics with zero external scripts or tracking, and are served over HTTP/2 with full GitHub Camo proxy caching.

How do I get my tool listed on DevShelf if it's not indexed yet? ▼

Simply submit a quick pull request to our GitHub repository (RitualDev-Lab/DevShelf). Once merged, our automated CI/CD pipeline deploys your dossier within 60 seconds!
