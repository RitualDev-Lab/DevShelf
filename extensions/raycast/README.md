# 🚀 DevShelf Raycast Extension

Search 500+ curated developer tools, free APIs, AI agents, CLI utilities, and startup perks directly from your Raycast launcher on macOS and Windows.

---

## ⚡ Features
- **Instant Search**: Query across tool names, categories, languages, and descriptions.
- **Copy Badge**: Instant hotkey (`Cmd+Shift+B`) to copy the official "Featured on DevShelf" Markdown badge for your own repository.
- **Random Gem**: Roll a random verified developer tool with `Cmd+R`.
- **Zero Registration**: Powered by the free DevShelf Public API v1.

---

## 🛠️ Local Development & Installation

```bash
# Navigate to the extension directory
cd extensions/raycast

# Install dependencies
npm install

# Run in Raycast developer mode
npm run dev
```
