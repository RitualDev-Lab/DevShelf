# 📚 DevShelf for Visual Studio Code

Search 500+ curated developer tools, free APIs, AI agents, CLI utilities, and developer perks directly inside Visual Studio Code without leaving your editor.

---

## ⚡ Features
- **Quick Pick Search (`Ctrl+Shift+P` / `Cmd+Shift+P`)**: Run `DevShelf: Search Free Developer Tools & APIs` to filter across 500+ verified tools.
- **Instant Actions**:
  - Open tool homepage or GitHub repository.
  - Copy clean, tracking-free URL to clipboard.
  - Copy "Featured on DevShelf" Markdown badge for your project's `README.md`.
- **Random Tool Roll**: Run `DevShelf: Pick a Random Free Tool` to discover hidden gems.

---

## 🛠️ Usage
1. Open the Command Palette (`Ctrl+Shift+P` on Windows/Linux, `Cmd+Shift+P` on macOS).
2. Type `DevShelf: Search` and press `Enter`.
3. Search for any technology (e.g. `docker`, `postgres`, `ai`, `testing`).
